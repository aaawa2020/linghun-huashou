# 灵魂画手 · 多人在线联机你画我猜

一款打开浏览器就能玩的你画我猜小游戏：一个人画，其他人猜，灵魂画手，全场爆笑。

**在线试玩：https://aaawa2020.github.io/linghun-huashou/**

## 玩法

- 房主建房后生成邀请码，把邀请码发给好友，好友输码即可加入房间
- 每轮一位玩家当画手，从词库抽词作画，其他人看画猜词，在聊天框里抢答
- 第一个猜中的玩家额外 **+15 分**；所有人都猜中、或倒计时结束，本轮自动结算
- 全部回合结束后按总分排名，看看谁才是真正的灵魂画手

## 功能

- **多人在线联机**：基于 PeerJS 的 P2P 连接，无需注册、无需服务器，浏览器打开即玩
- **房间参数可调**：人数上限 2~20 人、总回合数 1~50 局、每轮限时 15~300 秒，都由房主说了算
- **自定义词库**：内置词库之外，还能添加「兄弟专属」自定义词，整点只有你们懂的梗
- **房主管理**：对局中途可以继续拉人进来，也能踢出离线或捣乱的玩家
- **本地试玩模式**：没凑齐人也能先点「立即开玩」，一个人熟悉画布和流程
- **画布工具**：多色画笔、橡皮、撤销，触屏和鼠标都顺手

## 技术说明

- 整个游戏就是**一个 `index.html` 文件**（约 174 KB），无构建、无依赖打包，丢到任何静态托管上就能跑
- 联机走 [PeerJS](https://peerjs.com/) 公共云服务做信令与 P2P 直连，对局数据在玩家浏览器之间直接传输
- 本仓库通过 GitHub Pages 部署，推送到 `main` 分支后自动更新线上版本

## 本地运行

下载 `index.html`，用浏览器直接打开即可；或在目录下起一个静态服务器：

```bash
npx serve .
```
